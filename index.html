Disclosure Cold Archive

A personal archive and restore utility for disclosure documents.

本应用使用 restic 和 rclone，将所有者选定的公告 PDF 与解析文件保存到指定的 Google Drive 归档目录，并在需要时恢复到本机缓存。归档内容在上传前由 restic 加密。

Google Drive access

The desktop utility connects to the account explicitly authorized by its owner. It stores encrypted archive repository data in the configured Google Drive folder and retrieves that data for local use. This website is informational; it does not sign users in or handle archive data.

The Drive permission requested by rclone can cover all files in the authorized account. The configured archive folder limits where this integration operates; it does not narrow the underlying Google OAuth permission.

This is a personal utility, not an open registration service. The owner controls authorization, archive retention and any file removal.
