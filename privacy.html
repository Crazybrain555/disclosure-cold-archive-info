Privacy policy

Disclosure Cold Archive
Effective date: 6 November 2026

This policy covers the personal Google Drive archive integration operated by Crazybrain555. It does not describe unrelated services or later uses of documents outside this storage integration.

Information accessed and purpose

After the owner authorizes Google Drive access, the integration uses file and folder identifiers, repository file names, sizes and other file metadata, archive content, and account storage-quota information to store, verify and restore encrypted archives in the configured folder.

rclone requests the Google Drive scope needed to work with an existing folder. Google may describe this permission as allowing access to all Drive files. Operations are configured to use the selected archive folder; this application setting does not restrict the scope of the token Google issues.

Storage and security

restic encrypts archive contents before upload to Google Drive. OAuth credentials and repository passwords are stored in private configuration on the owner's computer. Restored files and integrity catalogs are stored locally; active cache entries are protected from eviction while in use. Restored files are plaintext and depend on the computer's access controls.

Use and sharing

Data is used for the owner's archive, integrity verification and restoration requests. The integration sends archive data and necessary request metadata to Google Drive and restores archive data to the owner's computer. It does not sell Google user data, use it for advertising, or send it to model-training services.

Google's own handling of its service is governed by Google's privacy policy. This informational website uses no application analytics, tracking scripts, sign-in forms or archive uploads. If hosted on GitHub Pages, delivery of this website is also subject to GitHub's privacy statement.

Retention, revocation and deletion

The owner controls archive retention. Local restored copies may be evicted according to cache limits. Revoking this application's access from the Google Account connections page prevents future access using that authorization; it does not automatically remove already stored Drive archives or local copies. The owner can remove these separately when no longer needed.

Changes and contact

This policy will be updated before the integration adopts a new use of Google user data, and new consent will be requested where required. For questions or data-handling requests, contact the operator through the GitHub profile.
